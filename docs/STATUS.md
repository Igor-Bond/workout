# Состояние реализации по ТЗ

Требование §49: для каждого параграфа фиксировать состояние.

Обозначения:

- **Готово** — сделано и проверено
- **Частично** — работает не в полном объёме, в скобках чего не хватает
- **Не начато** — кода нет
- **Снято** — исключено из плана по договорённости
- **—** — раздел описательный, реализовывать нечего

Отметка «в версии 1 было» означает, что функция работала до переработки и
её предстоит написать заново по ТЗ. Код версии 1 лежит в `legacy/` и в
приложении не участвует.
