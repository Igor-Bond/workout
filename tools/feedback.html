Отзывы тестировщиков

Читает коллекцию feedback и показывает ответы. Правила Firestore по умолчанию запрещают её читать кому бы то ни было — этим инструментом пользуется владелец, и доступ ему открывается отдельным правилом, по его собственному идентификатору.

Не выполнен вход.

Идентификатор владельца

Вставьте его в docs/firestore.rules вместо ВАШ_UID и опубликуйте правила: консоль Firebase → Firestore Database → Rules → Publish. 









Если чтение отклонено


    
    
  1. Войдите — идентификатор появится выше.
    2.

        match /feedback/{entry}, строку allow read.
    3. 
    
  3. Опубликуйте правила в консоли Firebase.
    4. 
    
  4. Нажмите «Загрузить отзывы» снова.
