# Версия 1

Приложение до переработки по `docs/SPEC.md`: один `app.js` со всей логикой,
хранение в `localStorage`, последовательное выполнение подходов.

Файлы лежат здесь как точка возврата, из приложения не подключаются и в
`sw.js` не кэшируются.

Удалить можно после того, как перенос данных (§37) будет проверен на
реальной истории — до тех пор это единственная копия рабочего кода,
которым эти данные создавались.
